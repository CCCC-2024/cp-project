# Final Project — Computational Focus Stacking (Group 14)

Based on *Spatially-Varying Autofocus* (Qin, Sankaranarayanan, O'Toole, ICCV 2025).
The paper focuses each region at a different depth optically; we do it in software:
shoot a focal stack, align it, pick the sharpest frame per pixel, and fuse into an
all-in-focus image plus a focus map.

## Layout
```
lab_project/
├── src/            code (one file per step: stack_io, align, sharpness, fuse, experiments, make_figures)
├── data/raw/       focal stacks, one folder per scene: scene01/01.jpg, 02.jpg, ...
├── docs/           assignment, proposal slide, paper, capture notes (and later the report / final slides)
├── results/        generated by the scripts (not committed until final)
└── requirements.txt
```

## Run
```
pip install -r requirements.txt
python src/experiments.py scene01      # baseline + ablations -> results/
python src/make_figures.py scene01 results/all_in_focus/scene01_baseline.png --crops x,y,s x,y,s x,y,s
```

## Pipeline
1. `align.py` — ECC affine registration (absorbs focus-breathing scale change)
2. `sharpness.py` — Laplacian / Tenengrad / modified Laplacian + Gaussian smoothing
3. `fuse.py` — argmax focus map, hard vs. soft blending, selective DoF (stretch)

## Deliverables
- All-in-focus image + focus map per scene
- Near / mid / far crop comparison: single frames vs. fused
- Ablations: number of frames (3/5/10), focus measure, patch size (sigma), hard vs. soft
- Stretch: selective DoF from the focus map, or compare with Helicon / Zerene

## Capture
Tripod, everything manual and fixed (focus, aperture, ISO, shutter, WB); 8–12 frames near → far;
file names keep order. Log every stack in `docs/capture_notes.md`, including what failed.
